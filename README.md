# homebrew-tap

Homebrew tap for [voxtype](https://github.com/ompurwar/smart-transcriber) — hold-to-talk
voice typing for macOS, with transcription on-device and no cloud services.

```bash
brew install ompurwar/tap/voxtype
```

This formula is copied from `packaging/homebrew/voxtype.rb` in the main repository. Fixes
there should be mirrored here; the CI in the main repo is the place to make them first.
